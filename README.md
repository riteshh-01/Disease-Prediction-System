# 🩺 AI Disease Prediction System

![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=for-the-badge&logo=Streamlit&logoColor=white)
![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Machine Learning](https://img.shields.io/badge/Machine_Learning-F7931E?style=for-the-badge&logo=scikit-learn&logoColor=white)

An intuitive, beautifully designed AI health assistant built with Python and Streamlit. This application takes standard vital signs and uses a pre-trained machine learning model to instantly analyze and predict potential underlying diseases or health conditions.

---

## ✨ Features

* **⚡ Lightning Fast AI:** Utilizes Streamlit's `@st.cache_resource` to cache the machine learning model in memory, ensuring instantaneous predictions without reloading overhead.
* **🎨 Modern & Clean UI:** Features a balanced, responsive two-column layout and custom CSS styling for an engaging user experience.
* **📊 Comprehensive Vitals Analysis:** Processes four critical physiological metrics: Age, Body Temperature, Heart Rate, and Oxygen Saturation.
* **🛡️ Bulletproof Error Handling:** Gracefully handles missing model files and invalid inputs, providing clear, actionable feedback to the user.
